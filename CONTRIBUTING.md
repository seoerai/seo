# Contributing to SEO & Generative Engine Optimization (GEO) Knowledge Hub

Thank you for your interest in contributing to the **SEO & GEO Master Knowledge Hub** maintained by [seoer.ai](https://seoer.ai)!

## 🎯 Contribution Principles

1. **First-Principles & Technical Rigor**: Focus on empirical search engine mechanics, rendering pipelines, Core Web Vitals algorithms, and AI Generative Engine Optimization. Avoid unverified black-hat tactics or superficial SEO myths.
2. **Clear Markdown & Visual Diagrams**: Use clean GitHub-Flavored Markdown, ASCII diagrams, Mermaid flowcharts, and actionable code snippets (JSON-LD, Robots.txt, Caddy/Nginx configs).
3. **English Standard**: Write all documentation in clear, international English.

## 🚀 How to Contribute

1. **Fork the Repository**: Create your feature branch (`git checkout -b feature/seo-topic-expansion`).
2. **Make Improvements**: Add or refine module `README.md` files.
3. **Submit a Pull Request**: Explain your additions, cite authoritative search engine documentation (Google Search Central, Schema.org, W3C), and submit for review.

Thank you for helping empower independent developers and search engineers worldwide!
